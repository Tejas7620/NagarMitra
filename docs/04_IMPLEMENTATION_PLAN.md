IMPORTANT:
Do NOT invent new product features.

The purpose of this design is to visually represent the approved implementation plan.

==================================================
DESIGN GOAL
===========

Create a premium, modern, technically credible hackathon product.

The interface should feel:

* professional
* intelligent
* trustworthy
* modern
* polished
* easy to understand during a live demo

Avoid:

* excessive neon
* unnecessary 3D
* random gradients
* excessive glass effects
* giant decorative elements
* complicated navigation
* visual clutter

Use subtle:

* glass surfaces
* depth
* gradients
* motion cues
* micro-interactions

only where they improve usability.

==================================================
SCREENS
=======

Design only the screens required by the implementation plan.

For each screen include:

1. Purpose
2. Main content
3. Primary action
4. Secondary actions
5. Data states
6. Loading state
7. Error state
8. Empty state

==================================================

Create reusable components:

* navigation
* buttons
* inputs

* badges

* charts

* status indicators
* loaders

* empty states

Create variants for states such as:

==================================================
DEMO EXPERIENCE
===============

The primary demo journey must be visually obvious.

A judge should understand:

WHAT IS THE PROBLEM?
→ WHAT DOES THE USER DO?
→ WHAT DOES THE SYSTEM ANALYZE?
→ WHAT RESULT IS PRODUCED?
→ WHAT ACTION HAPPENS?

within seconds.
